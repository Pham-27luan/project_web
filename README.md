Đề tài: Xây dựng website đặt vé xe

Mô tả sơ qua dự án

Website đặt vé xe giúp người dùng tìm kiếm và đặt vé nhanh chóng, đồng thời hỗ trợ quản trị viên quản lý hệ thống, tài khoản và dữ liệu vận hành. Hệ thống hướng tới sự tiện lợi, dễ sử dụng và đảm bảo bảo mật thông tin người dùng.

Các chức năng chính
Nhóm chức năng	Mô tả
Xác thực	Đăng ký, đăng nhập, đăng xuất
Admin	Quản lý lái xe, khách hàng, tài khoản
User	Trang chủ, đặt vé xe, xem hóa đơn, cập nhật thông tin cá nhân
